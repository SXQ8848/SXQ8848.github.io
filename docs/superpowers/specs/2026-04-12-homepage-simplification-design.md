# 主页精简 — 设计文档

**日期：** 2026-04-12
**状态：** 已批准，待实现
**作者：** SXQ + Claude（brainstorming session）

## 背景 & 目标

当前主页 `src/pages/index.js` 包含 hero 区 + 6 个滚动 section（SkillInventory / ProjectCards / StatsAchievement / Timeline / RecentUpdates / SocialLinks），内容过载且多数 section 填充数据稀薄。网站定位是"积累知识 + 记录日常"，不需要展示面板、成就统计、更新时间线这些自传性质组件。

**目标：**

- 主页保留 hero（头像 / SXQ 渐变标题 / typewriter / 描述），删除 6 个 section 和 2 个按钮
- hero 下方放 3 张并排的导航卡片，作为网站唯一入口
- docs 目录重组为两个一级类别（`learning/` + `life/`），对应前两张卡片
- 新建 `/about` 页面，保留 SkillInventory + SocialLinks 作为"关于我"展示

**非目标：**

- 不保留 ProjectCards / StatsAchievement / Timeline / RecentUpdates 组件
- 不保留 hero 区的 "Explore Docs" / "GitHub" 按钮
- 不给 /about 加 Timeline / Stats 等其他组件
- 不做旧 URL 301 重定向（个人站可接受 404）
- 不建立第二个 Docusaurus docs plugin 实例（YAGNI）
- 不改 typewriter 文案 / 背景图 / Particles / RainbowTrail / MusicPlayer / navbar 主标题

## 整体架构

五层改动：

1. **主页层** — `src/pages/index.js` 删除 6 个 section import 和使用，删除两个按钮，引入新的 `<HomeCards />`
2. **新组件层** — 新建 `src/components/Home/HomeCards.{js,module.css}`（3 张卡片）
3. **新页面层** — 新建 `src/pages/about.{js,module.css}`

5. **配置层** — `docusaurus.config.js` navbar 删除 Docs 链接

**视觉样式（复用 MC 玻璃风）：**

- 背景 `var(--sxq-card-bg)` + `backdrop-filter: blur(8px)`
- 2px 边框 `var(--sxq-card-border)`
- MC pixel 阴影：`inset 2px 2px 0 var(--sxq-mc-inset-light)` / `inset -2px -2px 0 var(--sxq-mc-inset-dark)` / `4px 4px 0 var(--sxq-mc-drop-shadow-strong)`
- Hover：`transform: translateY(-4px)` + 边框变 `rgba(110, 231, 183, 0.4)`
- 整卡是 `<a href="...">`，必须覆盖全局 `a` 下划线规则（`text-decoration: none !important` + `border-bottom: none !important`）
- 主题切换过渡：`transition: var(--sxq-theme-transition), transform 0.2s, border-color 0.2s`

**图标发光动画：**

```css
@keyframes cardIconPulse {
  0%, 100% { filter: drop-shadow(0 0 4px rgba(110, 231, 183, 0.4)); }
  50%      { filter: drop-shadow(0 0 12px rgba(110, 231, 183, 0.8)); }
}
.cardIcon {
  font-size: 2.5rem;
  animation: cardIconPulse 2s ease-in-out infinite;
}
```

**内部排版：** 图标（2.5rem）→ 中文标题（1.25rem 粗体，渐变文字复用 `.navbar__title` 那条渐变）→ 英文副标题（0.9rem `var(--sxq-text-muted)`）→ 描述（0.85rem `var(--sxq-text-subtle)`）

**布局：**

- 桌面：`display: grid; grid-template-columns: repeat(3, 1fr); gap: 1.5rem; max-width: 900px; margin: 2rem auto;`
- 移动端 `@media (max-width: 700px)`：`grid-template-columns: 1fr`

## 边界情况

1. **旧 URL 404** — `/docs/intro`、`/docs/ai/agent-intro`、`/docs/hardware/schematic-basics`、`/docs/tinkering/build-wiki` 全部失效。接受。
2. **卡片 `a` 覆盖全局下划线** — 必须加 `!important`，否则主 body `.main-wrapper a:not(...)` 规则会给卡片加绿色下划线。
3. **移动端卡片图标动画** — `filter: drop-shadow` 在旧设备上可能卡顿，用 `prefers-reduced-motion` 兜底。
4. **SkillInventory 和 SocialLinks 在 /about 页面** — 这两个组件原本的 `<section>` wrapper 已经有上下 padding，放在 /about 不会挤在一起。
5. **hero 删按钮后布局** — 描述文字和 heroCard 底部距离变紧，`.heroCard` 的 `padding-bottom` 可能需要微调保持视觉平衡。
